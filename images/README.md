# תיקיית התמונות (images/)

כאן שומרים תמונות שנשארות לצמיתות במשחק - בניגוד להעלאה דרך הדפדפן
(שנעלמת ברענון הדף), תמונות שמעלים לכאן ונשמרות ב-GitHub **יופיעו
במשחק לכולם, תמיד**, אחרי לחיצה על "🔄 רענן קטגוריות".

## איך יוצרים קטגוריית תמונות חדשה

1. ניכנסו לריפו ב-GitHub (הכתובת: `github.com/eyalravit-cloud/hidden-picture-gameshow`).
2. נכנסים לתיקייה `images/`.
3. יוצרים תיקייה חדשה בשם הקטגוריה (למשל `חיות משק`) - לוחצים
   **Add file → Create new file**, וכותבים בשם הקובץ:
   `חיות משק/placeholder.txt` (זה יוצר את התיקייה אוטומטית).
4. נכנסים לתיקייה החדשה ולוחצים **Add file → Upload files**, ומעלים
   את התמונות.
5. **חשוב:** שם כל קובץ תמונה (בלי הסיומת) הוא התשובה הנכונה במשחק.
   לדוגמה: קובץ בשם `פרה.jpg` ייצור פריט שהתשובה שלו היא "פרה".
6. חוזרים למשחק ולוחצים **🔄 רענן קטגוריות** (במסך הפתיחה או בפאנל
   המנחה) - הקטגוריה החדשה תופיע אוטומטית עם כל התמונות.

צריך לפחות 2 תמונות (עם שם קובץ תקין) כדי שהקטגוריה תופיע ברשימה.

## תיקיית `custom/`

זו תיקיית דוגמה ריקה - אפשר להעלות אליה תמונות ישירות (בלי ליצור
תיקייה חדשה) כדי לבנות קטגוריה מהירה, או למחוק אותה וליצור תיקיות
משלכם לפי קטגוריה.
