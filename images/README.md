# תיקיית התמונות (images/)

כאן שומרים תמונות שנשארות לצמיתות במשחק - בניגוד להעלאה דרך הדפדפן
(שנעלמת ברענון הדף), תמונות שמעלים לכאן ונשמרות ב-GitHub **יופיעו
במשחק לכולם, תמיד**, אחרי לחיצה על "🔄 רענן קטגוריות".

## התיקיות המוכנות

כבר יצרנו לכם תיקייה לכל נושא - פשוט העלו תמונות לתוך התיקייה המתאימה:

- `images/פירות/`
- `images/חיות/`
- `images/כלי רכב/`
- `images/דגלים/`
- `images/חברי כנסת/`
- `images/custom/` - לקטגוריה חופשית משלכם

## איך מעלים תמונות לתיקייה קיימת

1. נכנסים לריפו ב-GitHub: `github.com/eyalravit-cloud/hidden-picture-gameshow`.
2. נכנסים לתיקייה `images/` ואז לתיקיית הנושא הרצוי (למשל `images/פירות`).
3. לוחצים **Add file → Upload files** וגוררים את התמונות.
4. **חשוב:** שם כל קובץ תמונה (בלי הסיומת) הוא התשובה הנכונה במשחק.
   לדוגמה: קובץ בשם `תפוח.jpg` בתיקיית `פירות` ייצור פריט שהתשובה
   שלו היא "תפוח".
5. אפשר (ומומלץ) למחוק את הקובץ `placeholder.txt` שבתוך התיקייה אחרי
   שהעלו לפחות 2 תמונות אמיתיות.
6. חוזרים למשחק ולוחצים **🔄 רענן קטגוריות** (במסך הפתיחה או בפאנל
   המנחה) - הקטגוריה תופיע אוטומטית עם כל התמונות.

צריך לפחות 2 תמונות (עם שם קובץ תקין) כדי שהקטגוריה תופיע ברשימה.

## יצירת קטגוריה חדשה משלכם

רוצים נושא נוסף שלא ברשימה? יוצרים תיקייה חדשה תחת `images/` בשם
הקטגוריה (למשל `images/כלי נגינה/`) - לוחצים **Add file → Create new
file**, וכותבים בשם הקובץ: `כלי נגינה/placeholder.txt` (זה יוצר את
התיקייה אוטומטית). לאחר מכן מעלים תמונות אליה כמו בכל תיקייה אחרת.
